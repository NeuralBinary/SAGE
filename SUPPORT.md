# Support

Use [GitHub Issues](https://github.com/NeuralBinary/SAGE/issues) for reproducible bugs,
documentation gaps, and focused feature proposals. Include the SAGE version, Python/runtime and
database versions, deployment mode, relevant configuration with secrets removed, expected and
actual behavior, and the smallest safe reproduction you can provide.

Before filing, run `sage-doctor` and check the [getting-started guide](docs/GETTING_STARTED.md),
[configuration reference](docs/CONFIGURATION.md), and [operations guide](docs/OPERATIONS.md).

Do not use public support channels for vulnerabilities. Follow [SECURITY.md](SECURITY.md) for a
private report. Community support is best effort; no response-time or availability SLA is
provided.
